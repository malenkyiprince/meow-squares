# ୨୧ meow-squares ♡

**a tiny python program with a little kitty!** ฅ^•ﻌ•^ฅ

### ♡ what does it do?

meow-squares calculates the squares of all numbers from **1 to n**.

just enter a number, and your little kitty will show you the results! ♡

### ♡ example

```text
enter n: 5

1² = 1
2² = 4
3² = 9
4² = 16
5² = 25
```

### ♡ how to run

1. download `meow-squares.py`
2. open it with python 3
3. enter any positive integer
4. enjoy your squares! ♡
